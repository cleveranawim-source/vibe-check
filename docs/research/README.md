# 조사 산출물

이 폴더는 교육용 보안점검 서비스의 기준 자료를 2026-08-22 현재 상태로 정리한다.

- `REFERENCE_CATALOG.md`: 사람이 읽는 조사 보고서. 법적 성격, 적용 범위, 주의점, 제품 우선순위를 포함한다.
- `reference_catalog.json`: 서비스와 규칙 DB가 읽을 수 있는 구조화 목록. 72개 출처의 ID, 기관, 버전/날짜, 공식 URL, 적용 기능, 오용 주의를 담는다.
- `official-documents/`: 2026-08-27에 공식 사이트에서 내려받아 검증한 원문 스냅샷. PDF 29개와 교육부 원본 HWPX 1개, 출처 안내와 SHA-256 체크섬을 포함한다.

## 사용 원칙

1. 규칙은 카탈로그 원문 전체를 AI에 넣어 즉흥적으로 판정하게 하지 않는다.
2. 각 규칙에 `source_id`, 통제·조문 ID, 문서 버전, 시행 시작·종료일, 마지막 확인일을 저장한다.
3. 법률, 고시, 공식 안내서, 국제표준, 커뮤니티 지침을 결과 화면에서 구분한다.
4. 폐지·대체 자료는 과거 보고서 재현을 위해 `successor_id`와 함께 보관한다.
5. 개인정보와 비밀정보는 로컬 결정론적 탐지·마스킹 후 AI에 최소한만 전달한다.
6. 결과는 준법·안전 인증이 아니라 확인된 증거, 의심 정황, 정책 위험, 사람의 검토 필요 항목으로 구분한다.
