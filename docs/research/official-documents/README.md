## 검증 결과와 제외 항목

- 모든 PDF는 `pdfinfo`로 열어 페이지 구조를 확인하고 첫 페이지를 Poppler로 렌더링했다.
- HWPX는 ZIP 컨테이너 무결성 검사를 통과했다.
- 법령 본문처럼 공식 웹페이지만 있는 자료는 PDF로 임의 변환하지 않았다.
- 개인정보 유출신고 안내는 안내 웹페이지와 신고서 양식만 있어 별도 PDF를 저장하지 않았다.
- 개인정보 처리 방법에 관한 고시는 2026-08-20 시행 제2026-10호로 개정되었지만 공식 전문 PDF 첨부가 없어 이 스냅샷에서 제외했다. 카탈로그의 기존 제2025-5호 메타데이터는 후속 갱신이 필요하다.
- KrCERT의 중소기업 보안 취약 사례 PDF는 공식 다운로드 엔드포인트가 오류를 반환해 포함하지 않았다.
